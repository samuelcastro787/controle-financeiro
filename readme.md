# 💰 Controle Financeiro

Aplicação web para gerenciamento de despesas pessoais, com foco em usabilidade mobile e experiência semelhante a aplicativos bancários.

---

## 🚀 Funcionalidades

* ✅ Adicionar, editar e excluir despesas
* ✅ Controle por mês (persistido mesmo após recarregar)
* ✅ Parcelamento de despesas
* ✅ Marcar despesas como **pagas**
* ✅ Filtro por categoria com total específico
* ✅ Criação de categorias personalizadas (com cor)
* ✅ Persistência de dados com **LocalStorage**
* ✅ Interface responsiva (mobile-first)
* ✅ Destaque visual para despesas pagas

---

## 📱 Experiência Mobile

* Layout em formato de **cards**
* Botão flutuante para adicionar despesas
* Interface otimizada para celulares
* Rolagem dinâmica conforme quantidade de dados

---

## ⚡ Progressive Web App (PWA)

O projeto também funciona como um **PWA**, permitindo:

* 📲 Instalação no celular (Android e iPhone)
* 🔌 Funcionamento offline
* 🚀 Abertura rápida como app nativo
* 🖥️ Ícone na tela inicial do dispositivo

---

## 🧠 Tecnologias Utilizadas

* HTML5
* CSS3
* JavaScript (Vanilla JS)
* LocalStorage
* Service Workers (PWA)

---

## 🎨 Interface

* Tema escuro (dark mode)
* Design moderno e limpo
* Feedback visual:

  * Despesas pagas → opacidade reduzida + texto riscado
  * Categorias com cores personalizadas

---

## 💾 Armazenamento

Utiliza `localStorage` para persistência de dados:

* Mantém despesas salvas
* Mantém categorias criadas
* Mantém mês selecionado

---

## 📊 Funcionalidades de Controle

### 📅 Controle por mês

* Filtra automaticamente as despesas do mês selecionado

### 🏷️ Categorias

* Criação e remoção de categorias
* Filtro por categoria
* Total dinâmico por categoria

### 💸 Pagamento

* Controle de despesas pagas por mês
* Estado salvo localmente
